# Beauty & Wellness Data Science

**Internship:** Week 1 — Data Science Orientation & Problem Definition  
**Prepared by:** Abhay Tiwari  
**Market focus:** India

## Project overview
This project frames a data science problem for an online beauty and personal-care retailer: understanding which observable factors are associated with product-page conversion and repeat purchase.

## Business problem
Visitors browse beauty products, but not every visit becomes a purchase and not every first-time customer returns. The goal is to use privacy-safe e-commerce data to identify patterns by category, price/discount, reviews, acquisition channel, and customer cohort, then recommend experiments to improve the customer journey.
